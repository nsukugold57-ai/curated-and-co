Curated & Co.

Tagline: Thoughtfully Curated. Beautifully Gifted.

Project Overview

Curated & Co. is a fictional gift hamper business based in Pretoria, Gauteng, South Africa. The business offers thoughtfully curated gift hampers for different occasions and recipients.

Website Purpose

The website allows visitors to:

- Learn about Curated & Co.
- View available gift hampers and prices.
- Browse the hamper gallery.
- Add hampers to a shopping cart.
- Submit custom hamper requests.
- Contact the business.

Products

- Pretty in Pink Hamper – R699
- Gentleman's Essentials Hamper – R549
- Little One Hamper – R499
- Baby Care Hamper – R399
- The Luxury Gentleman Hamper – R799

Delivery Areas

Gauteng and Limpopo, South Africa.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure
